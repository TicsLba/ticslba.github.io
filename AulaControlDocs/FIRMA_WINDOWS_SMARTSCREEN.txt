IMPORTANTE:
El texto que Windows SmartScreen muestra como "Editor" o "Publisher" no se obtiene de los metadatos internos del EXE. Se obtiene de la firma Authenticode aplicada con un certificado de firma de código confiable.

El pipeline de Tablet Escolar está preparado para firmar el ejecutable cuando se configuren los secretos:
WINDOWS_CODE_SIGN_PFX_BASE64
WINDOWS_CODE_SIGN_PASSWORD

Si no existe un certificado Authenticode confiable configurado, la compilación sigue siendo funcional pero Windows puede mostrar "Editor desconocido" o una advertencia de SmartScreen.

Para obtener un editor verificado en equipos externos:
1. Adquirir un certificado de firma de código confiable (OV/EV o equivalente).
2. Completar la validación del nombre del editor con la autoridad certificadora.
3. Configurar el certificado en el pipeline.
4. Firmar TabletEscolarTeacher.exe con SHA-256 y sello de tiempo antes de distribuirlo.

La ausencia de firma Authenticode no modifica las funciones internas de Tablet Escolar, pero sí afecta la confianza que Windows muestra al usuario al ejecutar el archivo.
